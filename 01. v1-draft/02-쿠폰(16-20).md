# 02-상품-가격-혜택 (16-20)
## 16-20. 고객 쿠폰 발행 및 운영자 발급 및 사용 기록
### 고객 (16-17)
1. 이벤트로 쿠폰 받기
-> 내 쿠폰함에서 사용 가능한 수량 확인, 구매 시 사용
-> 주문서에 쿠폰 할인 항목 추가로 표기

2. 환불 
2.1 주문 전체 쥐소 시 
- 쿠폰 유효기간 내 주문 취소 시 복원 (유효기간 그대로)
- 쿠폰 유효기간 외 주문 취소 시 복원 불가
2.2 부분 취소 시
- if 10% 할인이면, 할인 금액 구매 수량 만큼 배분
-> 딱 맞게 떨어지지 않는 잔존 1원 어떻게 할지 검토
- if 조건 10% 할인, ex 5만원 이상 구매 시... 역시 검토
- 부분 취소로 인해 잔여 상품 금액이 무료배송 기준 금액 미만이 되는 경우, 배송비 부과 및 쿠폰 효력 재검토 기준 마련 필요(예: 무료배송 혜택 소멸 시 초기 배송비 차감 등 환불 정산 로직 적용)

3. 결제 실패 또는 주문 미확정 시, 재선택 가능

### 운영자 (18-20)
1. 쿠폰 발급 생성 & 복원 처리
- 1.1 정책 목록 (쿠폰코드, 쿠폰명, 할인금액, 최소 상품금액, 발급 수량, 발급 기간, 상태) 
- 1.2 발급 이력
(발급 일시, 고객 아이디, 정책 코드, 쿠폰 코드, 상태(발급, 사용, 복원))
- 1.3 복원 허용 정책 검토

2. 고객이 쿠폰 사용 시 사용 대기 상태
- 결제에 성공하면 쿠폰 사용 완료 기록
- 실패하면 쿠폰 대기 해제 후 다시 사용 가능

3. 발행된 쿠폰 수량 100개 중 99개 소진, 마지막 한 장 동시에 요청해도 1명만 승인... 두명 중 누구에게 발급할지 기준 필요

4. 쿠폰 남용 의심 시 대응 택
- 사용 제한 안내문 + 고객센터 문의
- 추가 본인확인 후 사용
