## 1-6. 주문 결제 시도, 승인 기록
### 고객
- 주문서에서 결제 수단 선택 (카드 이외에도 다수)
- (카드) 외부 결제앱 인증 완료 후 다시 앱으로 복귀 -> 승인 확인 후 주문 완료
- 외부 인증 취소된 경우나, 외부 앱에서 취소하거나 탭을 닫고 앱으로 돌아가도 입력된 내용이 유지(임시저장)
- 외부 앱이 닫히거나 네트워크 문제로 응답이 유실되면, 중복 결제가 발생하지 않도록 결제 결과 확인 로딩 페이지
- 복귀 링크가 유실되어 돌아오지 못한 경우에도, 앱을 다시 실행하면 기존 거래 확인 가능

- **PG 승인**  : 우리 서버에서 PG사에 승인 요청
- 결제 요청 : 같은 결제 요청이 연속으로 전달되어도 한 번만 처리

Q. 카드 결제를 택했지만, 카드 앱이 없다면...? 

### 운영자
***회사 서버가 승인 결과 조회***
- 고객 인증 결과 PG 전달 -> 서버가 PG01 승인 결과 확인 -> 승인 상태를 주문과 연결

- 결제 관리 탭에서 주문, 걸제 거래표 확인
- 같은 요청키로 다시 결제를 요청 시, 기존 결제 이력 조회
- PG 응답 지연 시, 조회 중 상태로 유지하며 실패로 단정 짓기 x
- 결제 승인 내역 / 주문 각각 1건 / PG 거래 번호, 중복 불가
- 고객앱에서 결과를 받지 못해도 기존 결제키 조회 후 주문을 확정

### 주문 실패 시 복귀
1. 외부앱 결제 실패 시에도 장바구니와 입력한 주소는 유지, 그러나 재시도 시점에서 가격 변동성 있음
- 외부 결제 앱에서 사용자가 결제 취소 시 마트앱으로 돌아오면 주문서로 돌아오기,
- 또는 결제 수단 선택으로 돌아오기
2. 결과 불명시 확인 방법
- 자동 조회 : 앱 복귀 시 자동으로 기존 거래를 조회하여 승인 상태를 확인 (조회 결과에 따라 재결제 필요할 수 있음)
- 사용자 조회 : 사용자가 직접 '결제 결과 조회' 버튼을 눌러 기존 거래를 확인 (또는 주문 완료 페이지를 통해)
- 위 둘 조건 모두 새 결제가 아니다.
