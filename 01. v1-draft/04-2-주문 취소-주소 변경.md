# 1. 취소·변경 요청 화면

## 1. 상품 준비 전 주소 변경

- 상품 준비 전에는 고객이 직접 주소를 변경할 수 있습니다.
- 준비 이후에는 지원담당 승인으로 변경합니다.

### 1.1 상품 준비 전: 고객 직접 변경

- 주문 상세
  - 배송지: 서울시 강남구 테헤란로 123, B마트 아파트 101동 1001호
  - 버튼: 배송지 변경
- 주문접수 상태에서 고객이 직접 변경 가능합니다.
- 경로: 주문 상세 > 배송지 변경
- 변경된 주소로 정상 배송이 진행됩니다.
- 안내 메시지: 상품 준비 전에는 바로 변경할 수 있어요!

### 1.2 상품 준비 이후: 지원담당 승인 변경

- 상품 준비가 시작되면 지원담당 승인으로 변경합니다.
- 지원담당자 승인 화면 (관리자)
  - 주문번호
  - 고객명
  - 현재 주소
  - 변경 요청 주소
  - 버튼: 주소 변경 요청하기
  - 버튼: 거절
  - 버튼: 승인
- 상품 준비가 시작되어 지원담당의 승인이 필요합니다.
- 지원담당이 운영 여건을 확인하고 변경 가능 여부를 판단합니다.
- 승인 시 변경된 주소로 배송이 진행됩니다.
- 배송지 변경으로 인한 추가 배송비가 발생하면 고객 동의를 얻어 진행

## 3. 예약 슬롯 변경 (도입 검토 미정)

- 예약 주문의 배송 시간(슬롯) 변경은 고객 편의와 운영 영향 검토가 필요하여, 현재는 정책 도입을 검토 중입니다.

  - 모레: 4/26(토)

  - 11:00 \~ 13:00

  - 15:00 \~ 17:00

### 3.2 검토가 필요한 사항

- 변경 가능 시간 기준 (언제까지 허용할지)
- 변경 시 기존 슬롯의 재확보 규칙
- 운영 영향 및 시스템 반영 범위
- 현재는 정책 도입이 확정되지 않았으며, 추후 결정될 예정입니다.
- 예약 시간 변경은 별도 검토 가능
  - 배송 예약 시간 변경은 서비스/운영 영향이 있어 별도 검토 가능하도록 구현됩니다.
