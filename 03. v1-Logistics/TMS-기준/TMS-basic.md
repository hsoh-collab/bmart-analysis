# 4. 핵심 책임 경계
구분TMS / Delivery의 책임다른 시스템의 책임주문과 배송어떤 물품을 누가 어디로 운반하며 실제로 인도했는지 기록OMS가 주문 수량·상태와 전체 이행 결과 관리재고와 운송출발지 인수·운송 중 사고·도착지 인계 사실 제공재고 서비스가 해당 사실을 검증하여 원장 반영현장 준비와 집하수행 주체 도착·인수·출발 관리MFC/WMS가 피킹·검품·포장·출고 준비 수행회수와 환불승인된 물품 회수·반송 및 인계 수행고객지원·OMS가 처리 자격을 판단하고 Payment가 환불 실행고객 배송비와 운송 원가계약에 따른 실제 운송 비용과 수행 근거 제공Commerce의 가격·정책 계약이 고객 청구 배송비 결정배송 슬롯과 처리 여력배차·운송 측 수용 가능 정보 제공현장 처리 여력은 MFC가 제공. 최종 슬롯 점유 원장은 지정된 단일 서비스가 소유
고객이 내는 배송비와 실제 라이더·운송사 비용은 별도 금액입니다. 무료배송이어도 운송 비용은 발생할 수 있으며, 비용 변경이 고객 결제금액을 임의로 바꾸면 안 됩니다.

# 5. 반드시 보장해야 할 원칙

주문·포장·배송 건·운행 건을 구분합니다. 한 주문이 여러 포장·배송으로 나뉠 수 있고, 한 운행에서 여러 배송을 수행할 수 있습니다.
상태의 의미를 구분합니다. 배차 수락, 물품 인수, 고객 도착, 인도 완료는 각각 다른 사건입니다. 위치가 목적지에 도달했다는 이유만으로 배송 완료를 확정하지 않습니다.
인계 사실을 양쪽에서 대사할 수 있어야 합니다. 물품 식별자·수량·시각·인계자·인수자와 필요한 증빙을 연결합니다.
재배차가 중복 수행을 만들면 안 됩니다. 기존 할당의 철회·종료를 확인하고 새 수행 주체에게 책임을 넘깁니다. 이미 물품을 인수했다면 실물 인계 절차도 필요합니다.
배송 실패가 주문 취소나 환불을 자동 의미하지 않습니다. 실패 사실과 물품 위치를 OMS에 전달하고 후속 결정을 따릅니다.
분할 배송을 정확히 집계합니다. 일부 배송 완료를 전체 주문 완료로 표시하지 않으며, 기존 정책의 10kg 초과 분할에 고객 추가 배달팁을 임의 부과하지 않습니다.
물품 위치와 재고 소유·가용 상태를 구분합니다. 운송 중 물품을 도착지의 판매 가능 재고로 미리 계산하지 않습니다.
결과 불명은 조회·대사로 복구합니다. 완료 응답 유실을 새 배송 요청으로 처리하거나, 오래된 이벤트로 완료 상태를 되돌리지 않습니다.
TMS / Delivery 명세에는 이 범주를 기준으로 운송 유형별 전체 흐름, 하위 시스템별 상태·판단 규칙, 7개 영역과의 협업, 물품 인계 및 장애·사고 복구 계약을 정의해야 합니다.
