# SCM / Replenishment 상세 비즈니스 로직 및 운영 기준 — CDC→PPC 범위

## 1. SCM Replenishment의 정의·하위 시스템·협업 경계


SCM은 **무엇을 언제 어디에 얼마나 공급할지** 결정하며 DC→PPC 보충 수요·계획·배분·실적 대사를 관리한다. 바로픽은 외부 공급사의 DC 신규 입고 실행을 구현 범위에서 제외하고, **DC에 이미 적재된 재고부터 출발**한다. 실제 출고·입고 원장은 WMS, PPC 현장 작업은 MFC Operations, 운송 계획·배차·ETA·운송 사건 추적은 TMS가 처리한다. TMS 범위는 CDC→PPC 거점 간 운송이며 이 문서는 CDC→PPC 보충 흐름만 다루며 고객 대상 흐름은 범위에서 제외한다.

### 1.1 적용 범위와 거래·실물의 기준

SCM / Replenishment는 PPC 수요·재고·기존 공급·DC 공급 가능량·운송/인수 여력으로 보충 필요량을 추천하고, PPC 관리자의 요청과 승인에 따라 공급 약속과 이관 계획을 관리한다. 공급업체 조달·구매발주·DC 신규 입고·매입정산은 이 문서의 실행 범위가 아니다. DC가 이미 적재한 재고를 출발점으로 하며 DC 부족이 자동 외부 조달을 발생시키지 않는다.

공통 상품/SKU 기준은 본사 상품 승인 뒤 WMS가 정본을 관리한다. SCM은 기준을 참조하고 센터 취급·보충 설정과 변경 요청을 연결한다. WMS는 DC/PPC 현물·예약·위치·재고 반영과 DC 작업/출발, MFC Operations는 PPC 현장 검수·적치·사용 준비 사실, TMS는 차량·운송·ETA를 확정한다. SCM의 추천·승인·입고예정은 어느 센터의 실재고도 직접 늘리지 않는다.

승인된 DC 초기 보유 재고부터 운영한다. 본 문서의 실행 범위는 CDC/DC→PPC 보충 발주·이관 계획·운송 요청·실적 대사다. 센터 간 출발 후 실제 DC 반송/역이관·타 PPC 전환은 초기 제외다.

### 1.2 하위 시스템

| 하위 시스템 | 포함하는 비즈니스 로직 |
|---|---|
| 공급 기준정보 | SKU·거점·보충 주기·리드타임·BOX/PLT 취급 단위·온도 제약 |
| 수요 집계 | PPC 출고/소비 추이·보충 이력·품절 및 계절 요인 수집 |
| 수요 예측 | 기간별 SKU·거점 수요 예측, 실제 소비와 예측 오차 분석 |
| 목표 재고·안전재고 | 목표·최소·최대·재주문점·서비스 수준·리드타임 정책 |
| 재고 현황 참조 | 거점별 가용·예약·이동 중·입고 예정·격리·소비기한 제한 분리 |
| 보충 필요 판정 | 예상 부족 시점과 보충 임계치 판정 |
| 보충 수량 결정 | 목표 대비 부족분 계산, 도착 예정 반영, 물류 단위 환산 |
| DC 배분 | 동일 SKU 공급 부족 시 MFC별 수요·우선순위로 가용량 배분 |
| 보충 계획 확정 | 출발·도착 거점, SKU/수량, 희망 출고·도착시각, 승인 |
| 출고·운송 요청 | WMS에 출고 지시, TMS에 거점 간 운송 요청 연계 |
| 도착·입고 대사 | 출고·이동·도착·검수 수량 및 차이 원인 대조 |
| 부분 공급·부족 대응 | 부분 승인·1회 실제 출발·분할 도착·미도착·새 요청 재계획 |
| 초과·임박 재고 대응 | 저회전·과잉·소비기한 임박, 공급 축소·재배치 검토 |
| SCM 실패 복구 | 중복 보충 방지, 늦은 재고 이벤트·출고 실패·분실 대응 |

각 행은 업무 범주이며 독립 마이크로서비스 수가 아니다. 상태의 최종 소유권·함께 확정할 수량/금액·실패 복구·운영 배포 경계를 기준으로 구현 단위를 정한다. 상위 범주에 반송·외부 입고·실제 자격 검증 등이 있어도 현재 제외된 실행을 자동 도입하지 않는다. 미설정 값은0/무제한으로 채우지 않고 영향 신규 업무만 보류한다.

### 1.3 다른 영역과의 협업

| 연계 영역 | 함께 정의해야 하는 업무 | 상대 영역이 소유하는 책임 |
|---|---|---|
| 관제 시스템 | 긴급 보충·부족 배분 승인 | 정책 변경 및 승인 |
| WMS | 재고·LOT·소비기한·실출고·실입고 | 실물 원장·출고/입고 |
| TMS | DC→PPC 이동 요청, 운송 예정·지연 | 운송 계획·배차 |
| MFC Operations | 입고 처리 여력·도착 검수·적치 | 현장 입고·적치·선반 보충 |

상품 정본은 WMS이며 본사 상품/품질 승인 권한과 관제의 정책 승인 역할을 구분한다. PPC 수령 시간대·슬롯과 현장 인수 여력은 MFC Operations가 확정한다. TMS는 CDC→PPC 운송 계획·배차·경로·ETA와 운송 사건을 관리한다. BI / Analytics는 원천 사건/지표 협업만 유지하고 상세 구현·별도 최종 파일은 제외한다.

직접 조회/검증 요청, 확정 사건 수신, SCM을 통한 간접 조율을 구분한다. 모든 시스템을 직접 호출한다고 가정하지 않으며 상대 시스템이 담당하는 기능를 복제하지 않는다. 같은 요청·사건의 재전송은 원결과를 조회하고 다른 내용을 같은 요청으로 덮어쓰지 않는다. 성공한 원장 반영과 실패한 통지/조회 갱신을 분리해 미완료 단계만 복구한다.

[확정 정책] 상품 식별은 E-낱개/B-독립 실물 묶음과 전역 공통8자리 일련번호를 사용한다. DC/PPC는 같은 SKU를 쓰되 센터별 재고·예약·위치를 구분한다. 센터 간 보충에는 구매 수량 상한을 적용하지 않는다. BOX/PLT는 상품이 아닌 물류 취급 단위이며 E/B포장 전환은 초기 지원하지 않는다.

### 1.4 핵심 경계·업무 결과의 판단

SCM은 필요한 공급량·우선순위 제안·PPC 수동 요청/승인·공급 약속을 소유한다. 상품과 DC/PPC 재고는 WMS, 현장 실적/여력은 MFC Operations, 운송 계획·배차·ETA·운송 증빙은 TMS가 소유한다. 계획 공급을 실제 현물로 바꾸지 않는다.

요청 접수·승인·작업 배정·실제 수행·원장 반영은 각각 다른 결과다. 물리 수량은 센터·SKU·LOT·상태·원실물 단위로 대사한다. 타임아웃·오프라인 기록·GPS 도착·설비 완료 신호만으로 최종 실물/거래를 확정하지 않는다. 권한·최신 버전·실제 증빙·남은 의무를 확인한 뒤 업무를 종료한다.

## 3. 보충 업무 전체 흐름과 상태 전이

보충 업무는 **같은 기준시각의 PPC 수요·재고 확인 → 부족 추천 → PPC 관리자 수동 요청 → CDC 공급·PPC 수용량 검증과 승인 → WMS 할당·실제 출발 → TMS 운송 → MFC Operations 실제 수령/WMS 반영 → 사용 준비·차이 종결**로 연결한다.

| 단계 | 확정할 업무 | 수량/약속의 의미 | 실패·경합 |
|---|---|---|---|
| 추천 | 적격 현물·기존 보충 계보·예측·안전량 | 아직 공급 약속/현물 아님 | 기준시각/단위 불일치는 계산 보류 |
| 요청·승인 | 수동 요청·배수·DC 가용·PPC 도착시점 수용량·회차 | 승인 범위의 공급 약속 | 희소 배분 미승인·용량 불명은 영향 승인 보류 |
| 할당·출발 | WMS 적격 할당·단일 출발·TMS 편성 | 같은 공급의 진행 단계. 공급량을 단계별 합산하지 않음 | 실제 출발 전 취소만 절차대로 요청 |
| 운송·수령 | 원출발·도착 예정·실수령·정상/격리 | 수령량은 미도착 예정에서 제외, 격리는 판매 현물 아님 | 미수령 잔량/품질/반영 대기를 구분 |
| 사용 준비·종결 | WMS 반영·정상/기한·적치·사용 준비·차이 해결 | 사용 가능과 행정 종결을 각각 확정 | 도착만으로 사용 가능 또는 전체 종결 처리 금지 |

재계산은 승인된 실행을 소급 삭제하지 않는다. 이미 출발한 공급의 목적지 변경·자동 역이관·실제 DC 반송은 초기 범위에서 제외하며, 신규 공급은 기존 잔량과 연결해 중복 보충을 방지한다.

## 4. 상품·센터·보충 기준

DC/PPC는 동일 SKU 코드를 사용하고 재고·위치는 센터별이다. 단품 E-와 밀봉 묶음 B-는 독립 취급 단위로 계산한다. 물류 BOX/PLT만 동일 SKU의 단위로 환산하며 E/B 포장 전환·가상 혼합 세트는 초기 미지원이다. 센터 간 보충량에는 구매 수량 상한을 적용하지 않는다.

상품 등록·바코드·규격·기초상품 구성 수량·보관/기한 기준은 관제 상품/품질 담당 승인 결과를 사용한다. DC/PPC는 허용 권한으로 취급 여부·안전량·재주문점·목표량을 설정한다. `[설계안]` 센터·SKU별 명시적 설정 → 상품군 기본 → 전사 기본 순으로 적용하되 같은 우선순위 충돌은 계산 보류한다. 기준 누락을 안전량0이나 무제한 수용으로 대체하지 않는다.

DC는8,600평·14,000 SKU·최대520만EA 보관 목표, 부산5개 PPC는 현재 설계 대상, 40~50개 PPC는 장기 공급망 목표다. 실제 가동40~50개를 전제해 일 수요를 자동 생성하지 않는다. PPC마다 취급 구색·온도별 슬롯·패킹·인수 여력이 달라 동일 카탈로그 전량 공급을 보장하지 않는다.

[확정 정책] DC14,000 SKU·최대 보관 목표5,200,000EA·8,600평을 공통 설계 기준으로 사용한다. 실제 가동/일출고량이나 시설 성능 검증 완료와는 구분한다.

## 5. 수요와 재고 포지션



### 5.1 입력과 기준시각

WMS의 PPC 적격 현물·센터 내부 예약·기한/품질과 MFC Operations의 작업·공간·인수 인력을 조회하고, WMS의 DC 공급 가능량 및 TMS의 출발/도착/ETA와 차량 제약을 결합한다. 비교 시각·단위·확정 범위가 맞아야 한다. 오래된 조회나 장애는0재고로 계산하지 않고 보류한다.

수요 예측은 동일 기간에 이미 반영된 수요와 중복되지 않는 신규 예상 수요만 반영한다. 재고 기준값에 이미 차감된 물량을 다시 차감하지 않는다. 품절 기간의 출고/소비 실적 0은 잠재 수요 0의 근거가 아니다. 신규 PPC·수요 급증·요일 변화는 별도 근거와 적용기간으로 조정한다.

PPC 규모 자료의 차등 검토 주기는 다음 `[설계안]`으로 보존한다. 이는 자동 발주 주기가 아니며 검토 후 PPC 관리자의 요청이 필요하다.

| 구분 | 보충 검토 주기안 | 제약 |
|---|---|---|
| 신선·유제품·고회전 및 냉동 고회전 | 매일 | 오전 우선 인수와 저온 처리 가능성 확인 |
| 중회전·냉동 중저회전 | 2~3일 | 요일별 분산·보충 재고·기한 확인 |
| 저회전 | 7일마다 | 필요 상품만 요청, 포장 배수·과잉/만료 위험 확인 |

ABC 회전율 등급은 냉동A·냉장B 등 공간코드와 다르다. SKU구성10%/20%/70%·판매비중70%/20%/10%는 실판매가 아닌 가상 모델이므로 실제 이력 없이 등급을 확정하지 않는다. 실제 검토 간격과 공급 리드타임은 회차·휴무·PPC 인수시간으로 검증한다.

### 5.2 보충 계산안

`[설계안]` 보호기간은 현재부터 다음 검토에서 요청한 물량이 실제 사용 가능해지는 시점까지다. DC 작업·출발 대기·운송·PPC 검수/적치가 모두 포함된다. 기간 내 총량뿐 아니라 다음 공급 전 품절 구간도 확인한다.

| 기호 | 의미 | 단위/범위 |
|---|---|---|
| H | 품질·기한·사용 준비를 통과한 PPC 현물 | 해당 SKU의 센터 간 보충 기준 단위 |
| F | 기존 보충 계보·동일 기간 집계와 중복되지 않는 신규 예상 수요 | 동일 단위·동일 보호기간 |
| I | 기존 공급의 미인수 유효 잔량 | 동일 단위, 기간 내 검수/적치까지 가능 |
| SS | 승인 안전재고 | 동일 단위 |
| m | 허용 이송 배수 | 동일 SKU 판매 단위, 양의 정수 |

목표량 = F + SS. 재고 포지션 = H + I. 신규 필요량 = 목표량에서 재고 포지션을 뺀 값과 0 중 큰 값이다. 기존 공급 계보의 유효 잔량 I는 같은 물량을 승인·할당·출발 문서별로 중복 합산하지 않는다.

희망량은 신규 필요량을 m의 배수로 **올림**한다. 실행 상한은 DC 공급량·PPC 온도별 수용량·차량 구획별 적재량·기한 내 취급 가능량 중 가장 작은 값을 m의 배수로 **내림**한 양이다. 최종 추천은 희망량과 실행 상한 중 작은 값, 미충족은 신규 필요량−추천량과0 중 큰 값이다. 올림으로 제약을 넘기지 않는다. 상한10·배수12라면 추천0이며12를 강제 승인하지 않는다. 올림/내림은 각각 바로 위/아래 정수 배수 선택을 뜻한다.

`[팀 확인 필요]` 수요 모델·기간·안전량·최소이송 배수는 SKU/센터별 승인이 필요하다. 복잡한 수요 버퍼 방식과 Min/Max 방식을 같은 대상에서 독립 실행해 요청을 중복 생성하지 않는다. 초기에는 검증 가능한 단일 계산안을 선택·승인해 적용한다.

### 5.3 입고예정의 유효성

승인·할당·출발 상태가 다른 문서라도 같은 공급 계보의 같은 수량이면 I에 한 번만 센다. 인수된 양은 I에서 제거하고 적격 현물 H로 전환한다. 격리·부적합·도착시각 불명·보호기간 이후 도착량은 I에서 제외하거나 위험 공급으로 분리한다. 재계산에서 제외해도 이동 중 원장 잔량을 삭제하지 않는다.

미승인 추천을 확정 공급으로 계산하지 않는다. 승인 공급도 실제 할당/출발·ETA 근거를 확인한다. 승인 계획은 재계산으로 삭제하지 않고 변경 필요사항을 별도 검토한다. 이미 인정한 공급이 늦게 도착하면 새 보충과 과잉이 생기는지 다시 평가한다.

### 5.4 같은 기준시각의 수요와 공급 계보

[설계안] 계산은 WMS의 PPC 적격 현물 H·품질/위치, 기존 보충 공급 I, 신규 예측 F, 승인 안전량 SS를 같은 기준시각·단위로 결합한다. 이미 차감된 물량을 H에서 다시 차감하지 않는다. 품절 기간의 출고/소비 실적 0은 수요 0이 아니며 신규 PPC·요일 변화와 예측 신뢰도를 표시한다.

목표S=F+SS, 포지션IP=H+I, 필요N=max(0,S−IP)다. max는 큰 값 선택이다. 이송 배수m이 양의 정수로 등록되면 희망량은 ceil(N/m)×m, 실행상한은 floor(제약 상한/m)×m, 추천량은 둘 중 작은 값이다. ceil은 올림, floor는 내림이다. 제약 상한은 DC 적격 미점유량·PPC 도착시점 공간/검수·차량 구획·기한 내 처리량의 최소이며 회차 전체 품목도 합산 검증한다. m 미등록은 실행 승인 대기이고0/임의1로 대체하지 않는다.

설명 사례 H18/I24/F72/SS18이면 S90/IP42/N48이다. m12·실행상한48이면 희망48·추천48·부족0이다. 공급 I24가 지연돼 보호기간 밖이면 I0으로 계산해 IP18/N72이며, 같은 공급이 늦게 들어올 가능성은 위험/과잉 검토로 남긴다. I를 계획에서 제외했다고 WMS 이동 중24를 삭제하지 않는다.

승인24→할당24→출발24는 같은 공급24다. 인수10이면 미인수14만 I 후보로 남기고 실제 수령/정상 준비를 확인한 양을 H에 반영한다. 승인 미출발과 실제 출발 잔량을 문서 계보로 구분하며 수령 격리·준비 미완료는 현재 사용 가능 H나 미도착 I에 중복 산입하지 않는다.

## 6. 보충 감지와 수동 요청

`[확정 정책]` PPC 재고가 안전량 미만이거나 재주문점에 도달하면 추천·팝업·알림을 제공한다. PPC 관리자가 추천과 실제 수요를 검토하고 SKU·요청량·일반/긴급·희망 도착을 지정해 **수동 요청**한다. 추천 생성이나 알림 확인으로 이관을 생성하지 않는다.

| 유형 | 접수·처리 | 목표와 제한 |
|---|---|---|
| 일반 | 승인된 오전 마감과 일정을 기준으로 접수 | 당일 오후·6시간 이내 공급 목표 |
| 긴급 | 수시 접수, 승인 후 작업/운송 우선 검토 | 2시간 이내 목표, 품질·안전·승인 생략 금지 |

정확한 오전 마감은 `[팀 확인 필요]`이며10:00 예시를 확정하지 않는다. 6시간/2시간은 계획 목표이고 자동 보상이나 도착 보증이 아니다. 긴급 권한·비용·수요 간 우선순위는 승인 정책을 적용한다.

동일 PPC·SKU·기간의 기존 유효 요청과 진행 공급을 확인한다. 재전송은 기존 요청을 반환하고 수량이 바뀌면 새 버전으로 심사한다. 다른 PPC·SKU·온도 제약 수요는 단순 합치지 않는다. 매일 오전 수령이라는 PPC 계획과 DC4회차 계획이 충돌하면 실제 수령 창·인력·도착 시간으로 후보 회차를 검토하며 자동으로 하나를 지우지 않는다.

## 7. DC 공급량·배분·승인



### 7.1 가용량과 승인선

`[확정 정책]` DC 공급 가능량 = 정상 보유 − 기존 유효 예약 − DC 안전재고이며 음수면0이다. WMS가 확인한 같은 기준시점 값을 사용하고 이전 요청의 확보량을 재사용하지 않는다. 품질·기한·위치 잠금 제약도 통과해야 한다.

일반 요청은 DC 관리자 승인, **요청량이 현재 DC 공급 가능량의50%를 초과**하면 본사 관제 추가 승인 대상이다. 정확히50%는 이 조건만으로 추가 승인을 요구하지 않는다. 1,000개 절대 수량 기준은 예시이므로 적용하지 않는다. 동시 요청으로 가용량이 달라지면 승인 직전 재검증하고 승인 결과와 사용한 기준을 남긴다.

PPC 공간·검수 인력·온도·차량과 기한 제약을 확인한 후 승인/부분 승인/반려한다. 부분 승인에는 PPC 재승인을 요구하지 않는다. 요청100·승인60이면 미충족40을 기록하며 승인된60을100으로 표시하지 않는다. 승인만으로 DC 예약 성공을 선언하지 않고 WMS 할당 결과를 별도로 받는다.

### 7.2 공급 부족 배분

부족 시 후보는 요청량·긴급성·다음 공급 전 부족 위험·PPC 인수 가능성을 함께 보여주고 승인자가 결정한다. 긴급이라고 이미 다른 PPC에 확보된 재고를 무단 회수하지 않는다.

`[팀 확인 필요]` 요청시각순·위험도순·비례 배분 중 확정 우선순위는 없다. `[설계안]` 같은 승인 우선순위 내에서 요청량 비례 계산 → 허용 배수 내림 → 남은 배수는 소수 잔여가 큰 순서, 동률은 요청시각·센터 식별 순으로 추천한다. 각 배정 후 공간·차량·요청 상한을 재검사하고 넣을 수 없는 잔량은 미배분으로 남긴다. 이는 승인자를 대체하는 확정 배분 정책이 아니다.

### 7.3 수용량·회차·희소 배분과 자동화 제한

보충 사용 가능시각은 다음 유효 출발회차+DC 준비+운송/경유+PPC 검수·적치를 선후관계로 계산한다. 현재부터 다음 검토 물량이 사용 가능해질 때까지를 보호기간으로 검토하고 휴무/수령 창을 무시한 고정 L+R을 강제하지 않는다. 총량이 충분해도 다음 공급 전 품절 구간을 별도로 보고한다.

동순위 A60/B36/C24·DC72·배수12의 비례 설계안은36/21.6/14.4를 내림해36/12/12, 잔여12를 B에 추천해36/24/12다. 각 센터 수용량·요청 상한과 전체 차량을 재검사하며 품절 위험·기존 약속·행사 우선순위의 사업 승인은 남아 있다. 이 예시를 자동 우선 배분 정책으로 확정하지 않는다.

최신 초기 기준은 추천→PPC 관리자 수동 요청→승인→WMS 할당→1회 실제 출발이다. 새 자료의 자동 승인·한 TRF 여러 출발·출발 후 목적지 변경/역이관 제안은 현재 실행에 포함하지 않는다. 승인 미출발 잔량의 자동 종료는 미결정으로 유지하며 새 공급은 기존 잔량과 연결된 별도 요청으로 중복 약속을 제거한다. 내부 선반 MOV 자동 생성과 센터 간 공급 수동 요청은 다른 업무다.

## 8. 이관 실행과 공급 약속

요청 → 필요 시 본사 승인 대기 → 승인/부분 승인/반려 → WMS 할당 → 피킹/검품/상차 → 실제 출발 → 운송 → PPC 정상 검수 인수 → 완료 또는 차이 조사 순으로 추적한다. 승인·작업·운송·품질·행정 종결은 별도 상태다.

**[확정 정책] 1요청1이관1출발**이다. 부분 승인/부족량을 같은 요청에서 두 번째 출발로 보내지 않는다. 추가 필요는 기존 미충족과 진행 공급을 검증해 새 요청으로 제출한다. 승인됐으나 미출발한 잔량은 취소·종료 근거와 남은 공급 의무를 기록한다. 잔량 자동 종료 여부는 팀 확인 전 자동 처리하지 않는다.

WMS 실제 출발에서 DC 현물·예약이 감소하고 같은 수량이 이동 중이 된다. TMS가 운송 상태·ETA를 갱신한다. MFC Operations가 원출발과 대사한 실제 수령량을 확정하고 WMS가 같은 양의 이동 중 해소와 PPC 정상/격리 현물 반영을 수행한다. PPC 합격량은 정상, 미판정·부적합량은 격리 현물로 귀속한다. 도착·등록·검수·적치는 다른 사건이며 정상 판정·적치·사용 준비까지 확인해야 공급 사용 가능으로 평가한다.

12개 출발·10개 실제 수령(정상8·격리2)이면 미수령2개는 이동 중 조사 잔량이며 격리2개와 다르다. 격리분은 미도착 공급 I와 사용 가능 현물 H에 모두 넣지 않는다. 이를 새 요청12개나 확정 손실로 자동 바꾸지 않는다. 뒤늦은 실제 수령은 원출발 잔량에 연결하며 기존 실적을 덮어쓰지 않는다. **출발이 한 번이어도 실제 검사 결과의 부분 인수 확정은 여러 번 발생할 수 있다.**

[채택 설계] DC→PPC 이관은 주문의 품목행 LOT 제한을 적용하지 않고 적격 FEFO 순으로 필요한 LOT 수를 배정한다. WMS는 실제 출발·예상 PPC 도착 적격성, MFC Operations는 실제 수령 적격성을 판정한다. 비율 잔여일수는 올림하고 신선 30%, 가공 등 20%와 30일 중 짧은 값, 단기 신선 출고의 2일 추가 하한을 적용한다. 기한 미달·ETA 변경은 공급 I의 사용 가능성을 재평가하며 수량만 맞춰 승인하지 않는다.

### 8.1 수령 사실과 반영 대기의 공급 평가

[채택 설계] PPC의 원수령 확정번호·원출발·확정량을 기준으로 공급 I에서 실제 수령분을 제거한다. WMS 이동 중 반영이 늦다는 이유로 이미 받은 물량을 미도착 공급으로 다시 계산하지 않는다. 정상 판정·준비가 완료된 수량만 적격 현물 H에 포함하고 격리/준비 미완료는 제외한다. 연계 미반영만으로 새 보충을 중복 요청하지 않으며 실제 부족은 같은 기준시점의 H/I로 재계산한다. 수량이 모순되면 계산 확인 대기·관제 조사로 분리하고 원수령을 취소하지 않는다.

출고 회차는 DC 계획과 PPC 실제 수령 창·검수 인력/공간·TMS 경로/도착 조건이 함께 승인돼야 실행 가능하다. 일반6시간·긴급2시간은 목표이며 수령 창 미등록을 임의로 메우지 않는다. 필요한 설정이 없으면 해당 공급 후보를 실행 보류하고 이유·담당을 표시한다. 이미 운송 중인 물량은 안전 수령을 조율하며 원출발 삭제·자동 역이관으로 우회하지 않는다.

### 8.2 운송·사용 준비·행정 종결

운송 수량 대사는 실제 출발=실제 수령 누계+미수령 이동 중+승인 손실로 확인한다. 사용 준비는 WMS 반영·정상/기한·위치·사용 준비가 충족된 양만 인정한다. 행정 종결은 미출발 잔량·수량 차이·품질 사건·비용/책임의 남은 의무와 담당을 확인한다. 차량 도착이나 수량상 일치가 품질 사건의 종결은 아니다.

MFC 현장 수령과 WMS 반영 응답을 분리한다. 실제 수령 사실을 확인한 양은 추가 미도착 공급으로 다시 세지 않지만 WMS 반영과 적격 준비가 확인되기 전 사용 가능 재고로 약속하지 않는다. 수량/버전이 모순되면 해당 계산 확정을 보류해 원수령·원출발을 대사한다. 보충 지연을 이유로 SCM이 다른 업무 영역의 예약이나 이행 상태를 직접 변경하지 않는다.

## 9. 지연·품질·차이·취소



### 9.1 공급 지연과 재계산

ETA 변경 → PPC 수령 인력/창·품질/기한 → 유효 공급 I → 다음 공급 전 부족 위험 순으로 평가한다. 필요하면 추가 추천·긴급 요청 검토를 제시하지만 PPC 수동 요청·승인을 거친다.

기한 임박 자동 긴급이송 요청이라는 공통 품질 초안은 수동 보충 정책과 충돌한다. 초기에는 경보·긴급 요청 **후보**만 자동 생성하고 실제 이관 신청은 PPC 수동 요청·승인 흐름으로 넘긴다. 이 범위 조정은 팀 확인 대상으로 관리한다.

### 9.2 차이와 사고

부족·초과·오배송·온도이탈·파손은 출발 실적·차량/상하차·봉인·PPC 재계수로 조사한다. 정상 합격량, 현재 부적합 실물 보관량, 미도착량을 분리한다. [채택 설계] 원출발과 대사한 실제 수령량 전체는 PPC 정상/격리 현물로 귀속하고 이동 중에서 한 번 해소한다. 검수 합격량만 정상, 미판정·부적합량은 격리이며 사용 가능은0이다. 현장 수령 사실은 MFC Operations가 확정하고, 같은 결과의 PPC 정상/격리 재고 반영과 이동 중 해소는 WMS가 수행한다. 격리품 실제 폐기는 WMS가 PPC 격리에서만 차감하고 미수령 잔량은 별도 유지한다.

차이 조사는3영업일 내 처리하고 추정손실10만원 초과는 본사에 상신한다. 사고 손실은 승인 전 자동 차감하지 않는다. 사건 종결은 본사 재고 책임자 또는 운영 본부장의 전자서명을 확인한다. 수량별 추가 상신 기준은 미확정이다. 수량 대사 완료와 품질 사건 종결은 별도로 확인한다.

### 9.3 취소·복구

출발 전 승인 취소는 SCM이 접수하고 WMS 작업 중지·실물 복귀·예약 해제 결과를 확인해 확정한다. 할당·피킹·상차 수량이 남아 있는데 계획만 삭제하지 않는다. 출발과 취소가 경합하면 실제 먼저 확정한 상태로 심사한다.

출발 후 이관 취소·역이관·강제 반송·PPC 간 전환은 초기 미지원이다. 이동 중 문제는 목적 PPC의 안전 검수·차이 처리로 연결한다. 품질상 사용 불가와 실제 반송 실행 가능 여부는 별개이며 부적합품을 정상 인수시키거나 미지원 역이관을 자동 생성하지 않는다.

## 10. 선반 보충과 공급망 보충의 경계

WMS와 MFC Operations의 센터 내부 선반 보충은 등록 최소 이하에서 자동 계산·작업 생성하고 사람이 실제 이동한다. SCM의 DC→PPC 보충은 추천 뒤 PPC 수동 요청이다. 내부 위치 이동과 센터 공급 요청을 같은 자동 보충 엔진으로 실행하지 않는다. 센터 내부 리저브가 부족하면 SCM 공급 검토 대상으로 넘기며 임의 외부 발주를 만들지 않는다.

## 11. 연계·장애·권한

같은 입력·기준시각·정책 버전의 재계산은 기존 결과를 반환한다. 승인 중 재계산이 일어나면 승인본을 보존하고 차이를 검토한다. 공급 약속 변경은 WMS 진행 실물·TMS 운송·PPC 예정에 영향을 확인하고 미출발 범위에서 새 버전으로 승인한다.

WMS 요청 응답 유실은 기존 할당/작업/출발을 조회한다. 성공한 출발을 다시 지시하지 않는다. PPC 인수 이벤트가 먼저 도착하면 원출발을 확인할 때까지 대기하며 음수 잔량으로 맞추지 않는다. 계획·재고·운송·수령의 부분 실패는 완료된 영역과 미해결 의무를 분리해 교대한다.

요청자·DC 승인자·본사 승인자·현장 실행자를 구분하고 권한은 센터·업무·현재 상태로 검사한다. 관제는 승인·사건 결과를 관리하며 SCM/WMS의 수량을 직접 변경하지 않는다.

### 11.1 출발 후 이관 사고 처리의 채택 기준

[채택 설계] DC 실제 출발 이후에는 원이관 취소·타PPC 경로 전환·자동 역이관/강제반송을 지원하지 않는다. 목적 PPC에서 실제 물량을 확인해 합격분만 정상 인수하고, 의심/부적합품은 온도를 유지한 별도 위치에 안전 보류한다. 정보 오류나 의심이 해소된 적격품만 재검수 후 인수할 수 있으며, 부적합 확정품은 본사 품질 책임자의 승인과 실제 폐기 증빙으로 처리한다. 실제 DC 반송은 초기 구현 범위에서 제외한다.

원출발·인수 실적을 지우거나 반송 의사만으로 DC 재고를 늘리지 않는다. 미해결 수량과 보관 책임·현재 위치를 유지하고, 폐기는 같은 물량을 소유한 원장에 한 번만 반영한다. 격리품 처분과 미수령 잔량은 별도 대사하며 동일 손실을 두 번 차감하지 않는다.

## 12. 운영 제한·보류 현물·예정 공급의 사용 경계

[채택 설계] DC는 WMS, PPC는 MFC Operations의 운영 제한 정본으로 공급·수령·공간을 검증한다. 출고/수령 중지나 확인 불명은 해당 신규 실행을 보류하며 SCM이 제한을 해제하지 않는다. 이미 출발한 물량은 취소하지 않고 TMS·PPC·관제에 안전 수령 방안을 요청한다. 제한으로 ETA/수령 가능성이 바뀌면 공급 I를 재평가하며 새로운 추천도 수동 요청·승인을 거친다.

안전재고는 센터·SKU 합계 보호량이며 LOT별 가상 예약을 추가하지 않는다. 보류량은 적격 현물에서 한 번 제외한다. 동일 수요를 신규 예측 F에 중복 산입하지 않는다. 수령된 격리품은 미인수 공급 I와 사용 가능 현물 H에서 모두 제외한다.

예정 공급 I는 보충 계산에만 사용한다. 승인·출발·ETA 확정·실제 수령만으로 사용 가능 재고를 보장하지 않고 정상 판정·적치·사용 준비 이후 현재 현물로 반영한다. 지연·격리·부족 시 I를 감액/제외해 재계산하며 실제 재고 원장을 직접 수정하지 않는다.

## 14. 미결정·운영 승인 대기와 적용 제한
