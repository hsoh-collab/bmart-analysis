### TMS

1. scm : 컨플루언스에 챗찍 내용 대충 분석 후 이해
2. scm : 추가 조사해서 md 파일 추가로 작성
3. wms : 컨플루언스 내용 분석 후 이해
4. 고객을 ppc로 변경해서 새로 분석 (커머스랑 OMS 제거한 버전)
   * 발주 시스템은 scm 참고

### 8개의 영역
* Commerce (Main)
* OMS	
* Delivery

* WMS
* SCM / Replenishment
* MFC Operations (PPC와 동일한 단어로 취급, 현재 문서에는 MFC로 정의)		
* BI / Analytics

이 영역들과 TMS가 통신 및 협업하는 내용도 상세하게 작성해야 한다. 각 영역들과 협업하는 내용, 상대 영역의 소유와 TMS 영역 소유의 업무를 구분 짓기 (연계 내용 상세히)
