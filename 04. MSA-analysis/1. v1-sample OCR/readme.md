# Prompt
각 이미지의 내용을 텍스트로 그대로 추출해 주세요. 이 단계에서는 정리·요약·재구성을 하지 않습니다.

[규칙]
1. 이미지 순서대로 처리하고, 각 이미지 앞에 "### 이미지 N" 형태로 번호를 붙입니다.
   (파일명이 있으면 파일명도 함께 표기)
2. 이미지에 있는 글자는 한 글자도 바꾸지 말고 원문 그대로 옮깁니다.
   맞춤법이나 표현을 고치지 마세요.
3. 글씨가 흐리거나 불확실한 부분은 추측하지 말고 [불명확: 보이는 대로 적기] 로 표시합니다.
4. 도표, 다이어그램, 화살표, 표는 텍스트로 구조를 풀어서 설명합니다.
   - 표 → 마크다운 표
   - 다이어그램 → "A → B → C" 형태 또는 구성요소와 연결 관계를 목록으로
   - 도식에서 읽히는 라벨은 모두 포함
5. 코드가 있으면 코드 블록(```)으로 옮기고, 언어를 표기합니다.
6. 이미지에 글자가 거의 없고 그림만 있는 경우, "[그림: 무엇을 보여주는지 한 줄]"로 적습니다.
7. 내가 이미지에 없는 내용을 보충하거나 해석하지 마세요.
